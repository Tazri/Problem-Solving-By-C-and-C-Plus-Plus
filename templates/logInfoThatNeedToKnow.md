**by default log function base is 2 if not mention :**

## main Fundamental

```cpp
b^x = n
then :
logb(n) = x; // base b
```

## Product Rules

```cpp
log(xy) = log(x)+log(y)
```

## Division Rules

```cpp
log(x/y) = log(x)-log(y)
```

## Power Rules

```cpp
log(x^k) = k*log(x)
```

## change base rules

```cpp
// logb is base b and logk is base k
logk(n) = logb(n)/logb(k)
```

## Fundamental Identity

```cpp
logb(b^x) = x then b^(logb(x)) = x
```

## Speical Case

```cpp
log(1) = 0;
logk(k) = 1
```

## Digit count furmola

```cpp
// number of digits of n in base k
floor(logk(n))+1;
```
